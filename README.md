# Bilheteira flip-flap · Sporting CP

Protótipo de uma página de venda de bilhetes desenhada como um quadro *split-flap* (o painel de palhetas dos aeroportos e estações), com os próximos jogos do Sporting na Liga Portugal 2026/27.

Abrir `index.html` no browser — não precisa de build nem servidor.

- Cada carácter é uma palheta animada que percorre o alfabeto até ao valor final.
- A disponibilidade é simulada: os estados mudam (À venda → Últimos → Esgotado; Breve → À venda) e o quadro "bate" ao atualizar.
- Tocar num jogo abre o painel de compra: bancada, quantidade, desconto de sócio e bilhete com código.
- Som opcional das palhetas (botão ♪ Som), layout compacto em telemóvel, respeita `prefers-reduced-motion`.

> Calendário, preços e lugares são ilustrativos — não é um serviço oficial de venda.
